# Results

`main_results.csv` records the reported mean and standard deviation across three independently trained CIFAR-10 victims for each activation. Query counts correspond to the optimized configuration (d=64), (P=1), (T=16), and (Q_{\mathrm{fit}}=12{,}000).

The PNG figures in `../figures/` are the supplied aggregate ablation plots. Their underlying per-seed JSON/CSV files were not included with this repository snapshot, so no synthetic source data or plotting program is claimed for them. Add the original numeric ablation summaries when they become available.
